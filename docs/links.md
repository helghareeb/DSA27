## Asking a question

1. Read the failing test — it states the contract.
2. Set a breakpoint and step through it (**F5** → *pytest: current test file*).
3. Then ask on the WhatsApp channel, **with the test name and the error text**.

"It does not work" is not a question.
"`test_pop_from_empty_raises` expects `IndexError` and I am getting `None`" is.
