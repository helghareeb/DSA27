## The course in six lines

| | |
|---|---|
| Code | **CS2101** if you are in AI · **IS122** if you are in Bio or SWE |
| Hours | **3** credit hours — 2 lecture + 2 lab |
| Prerequisite | CS1002 (AI) · CS012 and MATH012 (Bio, SWE) |
| Level | **Sophomore / Level 2** |
| To pass | ≥ 60% overall **and** ≥ 30% of the final **and** ≥ 75% attendance |
| Weeks | **15** teaching weeks |

*Sources: AI 2020 p. 44 · Medical Informatics 2014 p. 35 · Software Engineering
2013 p. 38. Full detail in [the course guide](course/00-course-guide.md).*

> The 2026 faculty bylaw (CS201) **does not govern current students** — it
> applies from next year. See [the coverage matrix](course/02-coverage.md) for
> what changes.
